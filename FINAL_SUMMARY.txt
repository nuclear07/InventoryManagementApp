💡 WHAT THIS APP DOES
================================================================================

It's a COMPLETE inventory management system with:

ADD PRODUCTS:
  - Name, category, quantity, minimum threshold
  - Automatic timestamp tracking
  - Full input validation

TRACK STOCK:
  - Record stock in/out transactions
  - Prevents negative inventory
  - Automatic product quantity updates
  - Optional transaction notes

ALERT SYSTEM:
  - 3 status levels (Normal, Low, Critical)
  - Color-coded indicators (Green, Amber, Red)
  - Summary cards on dashboard
  - Real-time updates

SEARCH & FILTER:
  - Real-time product search
  - Filter by category
  - Filter by stock status
  - Combined filtering support
  - Live result updates

HISTORY & LOGS:
  - Complete transaction log
  - Sorted by most recent
  - Color-coded entries
  - Full details displayed

OFFLINE-FIRST:
  - Works without internet
  - All data stored locally
  - Firebase-ready for sync
  - Automatic recovery
