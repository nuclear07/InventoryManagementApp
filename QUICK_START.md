📞 IF YOU GET STUCK
================================================================================

Problem: Can't find a file
  → Check FILE_COPY_INSTRUCTIONS.md for exact location
  → Verify directory structure is created

Problem: Compilation errors
  → Check you copied the entire file (including imports)
  → Make sure file is in correct directory
  → Run: flutter pub run build_runner build

Problem: Hive errors
  → Verify Hive.initFlutter() in main.dart
  → Check box names match constants
  → Run: flutter pub run build_runner build

Problem: Riverpod errors
  → Check all providers are properly imported
  → Verify ref is available (ConsumerWidget/ConsumerStatefulWidget)
  → Refresh providers with ref.refresh()

Problem: Navigation not working
  → Check GoRouter setup in app_router.dart
  → Verify route paths in navigation
  → Ensure GoRouter is in MaterialApp.router()

Problem: UI looks wrong
  → Check app_theme.dart is imported
  → Verify Material 3 is enabled
  → Check screen imports are complete

For more help: See IMPLEMENTATION_GUIDE.md (Troubleshooting section)
